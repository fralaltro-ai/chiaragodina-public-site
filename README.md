## Architettura e Contenuti

- **Single-Page Application (SPA):** navigazione istantanea senza ricaricamento pagina (`index.html`).
- **Asset Multimediali:** fotografie ottimizzate in formato moderno WebP e icone PNG ad alta risoluzione (`assets/images/`).
- **Documenti Didattici e Informativi:** archivio delle brochure, presentazioni formative e schede didattiche (`assets/docs/`).
- **Nessuna Dipendenza Esterna:** codice vanilla puro, accessibile e conforme agli standard WCAG 2.2 AA.
